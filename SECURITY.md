# Security

Report vulnerabilities privately through this repository's Security tab when
private vulnerability reporting is available. Do not post credentials, customer
photos, session cookies, signed URLs or exploitable production details in issues.

This repository ships no credentials and disables paid creation by default.
Use separate sandbox provider accounts during development. Keep Cloudflare
tokens in your private deployment environment and application secrets in the
Worker secret store. Never attach a trusted persistent production runner to a
public repository that accepts untrusted contributions.

The offline publication audit is a review aid, not a guarantee of secret-free
content. No third-party penetration test or security certification is claimed.
Operators must review account permissions, payment eligibility, retention, legal
copy and provider failure handling before enabling a public service.
